## [medium] slice-rvat5-01: From 430px to 599px wide, the sticky note covers the mobile tab row and blocks clicks on the 'racing', 'video bot' or 'about' tab
- file: src/components/StickyNote.module.css:12 (checklist gl-26 / atn-22 / atn-21)
- expected: Below 600px the divider tabs sit in a horizontal row above the pile (gl-26, README line 234), and every tab stays visible and clickable (atn-21: a tab click calls bring(id)). The sticky note is a non-interactive hint (atn-27). It must not cover or intercept clicks on a tab.
- actual: The note is a child of .stage and uses top:-22px, z-index:90 and pointer-events:auto. The stage has a transform, so it paints after the mobile tab row, which comes earlier in the DOM and has no z-index. The note's top 22px therefore extends up over the tab row. At widths where the row fits on one line, the note covers the right-hand tabs. Hit test on /#cv (share of each tab's area that elementFromPoint does not resolve to the tab): 430px: racing 51% (centre hits StickyNote_note), video bot 40%, about 17%. 480px: video bot 54% (centre hits the note), about 31%. 520px: video bot 43% (centre), about 43%. 560px: about 55% (centre). 599px: about 55% (centre). At 599px, Playwright's click on the 'about' mobile tab times out because the note intercepts the pointer, and the ABOUT label is almost fully hidden in the screenshot. Widths from 360 to 414px are unaffected (the row wraps to two lines, and only the 2-4% corner/shadow baseline registers). The implementation-notes deviation entry about the note covers only the overlap with the CV name/tagline, not the tabs.
- fix: In src/components/Tabs.module.css, inside the @media (max-width: 599px) block, add `position: relative; z-index: 1;` to the .tabsMobile rule. The row then stacks above the transformed .stage, whose z-index is auto, and so above the note, whose z-index 90 only counts inside the stage's own stacking context. Add an e2e test that loads /#cv at viewport widths of 430, 480, 560 and 599, and asserts that document.elementFromPoint at the centre of each nav[data-variant="mobile"] button falls inside that button, and that clicking the last tab (about) brings the about sheet to the top.
